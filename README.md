# InkTrace Web

[開啟 InkTrace Web](https://lctung.github.io/InkTrace-Web/)

## 開始書寫

1. 開啟「GitHub 設定」，填入帳號、資料倉庫名稱和有寫入權限的 Token。先按「儲存」，再按「測試連線」
2. 在首頁選一份稿紙。先寫左邊的「硬筆書法」，寫完按「上傳」
3. 右邊解鎖後寫「毛筆書法」。兩邊筆畫數相同時才能上傳毛筆。兩邊都上傳後，按「下一字」

## 常用操作

- 用「字格大小」調整兩欄的畫布。英文字母會顯示水平輔助線，數字可沿紅色基線對齊
- 想重寫時，使用該欄的「復原」或「清除」。若改了硬筆，要再上傳一次才會解鎖毛筆
- 「查看進度」可跳到其他題字。黃底代表已上傳一欄，綠底代表兩欄都完成，圓點代表有草稿
- 草稿會保存在目前的瀏覽器。請用同一個裝置、瀏覽器和網址繼續寫。在 GitHub 設定勾選「記住此裝置」並儲存，可在重新開啟後沿用 Token。共用裝置請取消勾選
