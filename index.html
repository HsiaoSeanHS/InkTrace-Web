個人資料管理

個人專用 · 程式、SVG 與備份統一存放於 HsiaoSeanHS/InkTrace-Web ↗（main）。

Token 以密碼加密保存在此瀏覽器。每次開啟網頁解鎖一次，即可連續上傳、備份與還原；重新整理或閒置 15 分鐘後需重新解鎖。

設定方式

建立 fine-grained token，僅選擇 InkTrace-Web 倉庫並授予 Contents「Read and write」，並設定到期日。首次設定 Token 與解鎖密碼，之後只需輸入解鎖密碼。同名稿紙、同字上傳會更新原檔。

備份與還原

換裝置前，先在原裝置按「備份到 Repo」，再於新裝置還原。上傳 SVG 不會自動建立完整備份。備份包含全部稿紙、草稿筆跡與上傳進度，不包含 Token；位置為 backups/latest.json，歷史版本保留於 Git。

還原會取代本機全部資料。可復原最近一次還原，重新整理後仍可使用。已釋放的筆跡只保留進度，原 SVG 仍在 Repo。公開 Repo 中的備份也會公開。

授權這次 GitHub 操作

僅用於 HsiaoSeanHS/InkTrace-Web。解鎖後可連續上傳；Token 只在每次操作期間短暫解密。

首次設定至少 12 個字元。忘記密碼只能清除後重設 Token。密碼與金鑰不會存入瀏覽器儲存空間，也不會傳給 GitHub。
